# Current Program Plan - A First, Human Environment C

## Product Outcome

Agents consume one fair-player environment boundary to complete ordinary STS2
runs. The same C semantics may later be implemented by another host without
moving host lifecycle, rewards or strategy into C.

## Current State

`preview.2` completed assisted and pure A+C journeys. `preview.3` preserves the
proven execution semantics while correcting public ownership, reference
ontology, read discovery and hot-path identity. It is source/test verified and
has one exact loaded/read-only local check; input delivery and an ordinary
journey remain pending.

## Delivery Order

1. Run a short `preview.3` input/successor regression on the exact loaded artifact.
2. Run one ordinary `he_pure` journey.
3. Complete hover/focus/tooltip/scroll/native-page information parity.
4. Move the five remaining adapter-library seams to neutral NativeUi ownership.
5. Shift normal product effort to A strategy, planning and recovery.
6. Admit Headless or Training work only as separate hosts/adapters with a
   conformance plan; do not alter C for speculative throughput work.

## Invariants

- STS2 owns rules and effects;
- C owns fair-player facts and current input authority;
- exact native operands remain host-local;
- one current owner/controller, stale rejection and execute-time validation;
- idempotent request and unknown-no-retry;
- D never authorizes or executes;
- source/test/build/install/load/Live/qualification are separate.

## Deferred

Headless runtime, Gym/RL wrapper, reward policy, MCTS, clone/fork, vectorization,
learning, arbitrary Mod compatibility, Companion and Workshop distribution.
